The application stores photos and sensor data in a folder that cannot be accessed via the phone's file manager.
To access these files, you must connect the phone to a PC using a cable, download the Android "platform tools" to your PC (https://developer.android.com/tools/releases/platform-tools), open a terminal within the "platform tools" folder, run "adb devices" to confirm that the phone is connected, and then execute "adb pull /storage/emulated/0/Android/data/com.Borges.CameraAndSensors/files/ ./captured_data" to retrieve the photos and data onto your PC.
